# FaceSwap Telegram Bot

Бот для замены лица с созданием стикерпаков.

## Возможности

- Замена лица на исторические персонажи
- Создание стикерпаков из результатов
- Реферальная система с лимитами
- Асинхронная обработка изображений
- Модерация контента (проверка лиц)

## Технологии

- **Aiogram 3.x** - Telegram Bot API
- **TensorFlow** - классификация изображений
- **OpenCV** - распознавание лиц
- **Face Fusion** - замена лиц
- **SQLite** - база данных
- **PIL/Pillow** - обработка изображений

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd faceswap-bot
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Настройте конфигурацию в app/settings.py:
```bash
CHANNEL_ID = -1000000000000  # ID канала для проверки подписки
YOUR_BOT_ID = "your_bot_username"
```
4. Запустите бота:
```bash
python main.py
```

## Использование
1. Старт: /start - начать работу  
2. Выбор пола: Указать мужской/женский  
3. Отправка фото: Четкое фото лица без очков/шляп  
4. Получение результата: фото + стикерпак

## Архитектура
```bash
Пользователь → Бот (Aiogram) → Валидация → ML-пайплайн → Результат
                    ↓
            База данных (SQLite)
                    ↓
           Реферальная система
```
## Мониторинг
Бот отслеживает:  
1. Время обработки изображений  
2. Использование памяти  
3. Статистику запросов  
4. Активность пользователей
