# tg-deepfakebot
Бот для замены лиц на нескольких заготовленных шаблонах, который создает из них стикерпак. Выбор пола и персонажа. Имеет проверку подписки на канал, счетчик попыток и реферальную систему. Реализована асинхронность, высокая нагрузка, система очередей.
 
# Введение
Этот Telegram-бот предназначен для работы с изображениями. Основной функцией является замена лица на изображении. Также, имеется ряд доп. функций:
1. Создание стикерпака;
2. Проверка и удаление файлов;
3. Проверка изображений на наличие нежелательного контента;
4. Классификация изображений и проверка на наличие заблокированных меток;
5. Реферальная система;
6. Проверка подписки на тг-канал;
7. Счетчик попыток.
Для выполнения вышеуказанных функций бот использует предобученные нейросетевые модели:
•	Модель классификации изображений MobileNetV2 – используется для классификации изображений и проверки их на наличие заблокированных меток. Модель обучена на большом количестве изображений и способна распознавать различные объекты и сцены;
•	Модель для проверки на неприемлимый контент NSFW Detector - специализированная модель, предназначенная для определения наличия нежелательного контента в изображениях. Она обучена на наборе данных, содержащем как безопасные, так и нежелательные изображения, что позволяет ей эффективно фильтровать контент.
•	Face Fusion – представляет собой технологию, используемую для объединения или смешивания черт лиц из разных изображений, создавая новое лицо, которое сохраняет характеристики исходных лиц.
 
# 1 Стек используемых технологий
1. Язык программирования:
•	Python 3.11: Основной язык программирования, используемый для разработки логики бота, обработки изображений и взаимодействия с нейросетевыми моделями.
2. Олсновные библиотеки и фреймворки:
•	Telegram Bot API: Библиотека для взаимодействия с Telegram API, позволяющая создавать и управлять ботами.
•	Pillow (PIL): Библиотека для обработки изображений, используемая для добавления водяных знаков и преобразования изображений в черно-белый формат.
•	TensorFlow/Keras: Фреймворки для разработки и использования нейросетевых моделей, применяемых для классификации изображений и проверки на наличие нежелательного контента.
•	NumPy: Библиотека для работы с массивами и выполнения численных операций, часто используемая вместе с TensorFlow для обработки данных.
•	opencv-python — это библиотека Python, которая предоставляет интерфейс для работы с OpenCV (Open Source Computer Vision Library), популярной библиотекой для компьютерного зрения и обработки изображений.
•	SQLite — это легковесная библиотека, которая предоставляет реляционную базу данных. Она не требует установки отдельного серверного процесса и хранит всю базу данных в одном файле на диске.
3. Нейросетевые модели:
•	Модель классификации изображений MobileNetV2 – используется для классификации изображений и проверки их на наличие заблокированных меток. Модель обучена на большом количестве изображений и способна распознавать различные объекты и сцены;
•	Модель для проверки на неприемлимый контент NSFW Detector - специализированная модель, предназначенная для определения наличия нежелательного контента в изображениях. Она обучена на наборе данных, содержащем как безопасные, так и нежелательные изображения, что позволяет ей эффективно фильтровать контент.
•	Face Fusion – представляет собой технологию, используемую для объединения или смешивания черт лиц из разных изображений, создавая новое лицо, которое сохраняет характеристики исходных лиц. Основные аспекты модели включают.
4. Разработка бота aiogram — это современная и мощная асинхронная библиотека для разработки ботов в Telegram на языке Python. Она построена на основе асинхронного программирования (asyncio), что делает её очень эффективной и быстрой, особенно при работе с большим количеством запросов.
 
# 2 Структура проекта
Проект имеет следующую структуру:
deepfakebot/ Корневая папка проекта.
	pycache/ Папка, содержащая скомпилированные байт-коды Python. Обычно создается автоматически и не требует ручного редактирования.
	app/ Основная папка приложения, содержащая основной код бота.
		init.py Файл, указывающий Python, что данная директория является пакетом. Может быть пустым или содержать начальную конфигурацию.
		bot.py Основной файл, содержащий код для запуска и управления ботом.
		functions.py Файл с вспомогательными функциями, используемыми в проекте.
		handlers.py Файл, содержащий обработчики команд и сообщений для бота.
		Settings.py Файл для настройки бота: API TOKEN, BOT ID, CHANNEL ID.

	models_onnx/ папка с моделями .onnx, которые нужно обязательно переместить в ~\Lib\site-packages\.assets\models. Без этого код не запустится, ссылаясь на отсутсвие .onnx файлов и путь.
	result_images/ Папка для хранения результирующих изображений, созданных ботом.
	stock_images/ Папка для хранения шаблонов, используемых для создания deepfake изображений.
	temp_images/ Папка для временного хранения изображений.
	wheels/ Папка для хранения .whl файлов, которые обязательны к установке.
	ff_inference.py Скрипт для выполнения инференса (вывода) с использованием Face Fusion.
	main.py Основной исполняемый файл для запуска приложения.
	referrals.db База данных SQLite, используемая для хранения данных о рефералах. 
 
# 3 Описание основных файлов
3.1 Главный файл main.py
Этот скрипт включает логирование и устанавливает уровень логов на INFO, что позволяет выводить сообщения уровня INFO и выше, такие как WARNING и ERROR. Это помогает отслеживать работу бота и диагностировать возможные проблемы.
Затем регистрируются различные обработчики (хендлеры) для обработки команд и сообщений. Обработчик команды /start регистрируется с функцией cmd_start, которая будет выполнена при получении данной команды от пользователя. Обработчик для изображений регистрируется с функцией handle_image, которая будет обрабатывать сообщения с изображениями. Обработчик для кнопок выбора пола регистрируется с функцией set_gender, которая будет выполнена при нажатии кнопок, передающих данные male или female. Обработчики для команд /set_gender, /menu и /refer регистрируются с функциями change_gender, show_menu и send_referral_link соответственно.
Асинхронная функция main запускает процесс поллинга новых сообщений от пользователей. Поллинг позволяет боту постоянно проверять наличие новых сообщений и обрабатывать их.
В конце скрипта проверяется, является ли данный скрипт основным модулем, который запущен. Если это так, запускается функция main с использованием asyncio.run(). В случае прерывания программы с клавиатуры (например, нажатием Ctrl+C), выводится сообщение "Бот отключён".

3.2 Инференс Face Fusion ff_inference.py
Этот скрипт импортирует библиотеку facefusionlib для замены лиц и использует модуль swapper для выполнения этой задачи. Также импортируется класс DeviceProvider из facefusionlib.swapper, который позволяет выбрать устройство для выполнения операций, например, CPU или GPU.
Основная функция в этом скрипте называется face_fusion_swap. Она принимает три аргумента: input_path, target_path и output_path. Эти аргументы представляют собой пути к исходному изображению, изображению-цели и месту сохранения результата соответственно.
Внутри функции создается объект face_fusion_swapper, который выполняет замену лиц с использованием метода swap_face из модуля swapper. Этот метод принимает несколько параметров:
•	source_paths: список путей к исходным изображениям.
•	target_path: путь к изображению-цели.
•	output_path: путь для сохранения результата.
•	provider: устройство для выполнения операции, в данном случае используется CPU.
•	detector_score: пороговое значение для детектора лиц.
•	mask_blur: степень размытия маски для более естественного результата.
•	skip_nsfw: параметр для пропуска изображений с нежелательным контентом.
•	landmarker_score: пороговое значение для детектора ключевых точек лица.
После выполнения замены лиц, результат сохраняется по указанному пути, и функция выводит сообщение с указанием пути к сохраненному файлу. Затем результат возвращается в качестве значения функции.
Таким образом, этот скрипт позволяет заменить лица на изображениях, используя библиотеку Face Fusion, и сохранять результат в указанное место.

3.3 Инициализация бота bot_init.py
Этот файл содержит код для инициализации бота и диспетчера, которые необходимы для работы Telegram-бота. Здесь создаются экземпляры бота и диспетчера, которые затем используются в основном файле `main.py` для регистрации обработчиков и запуска поллинга.
Описание кода:
- Импорт библиотек: Импортируются необходимые классы `Bot` и `Dispatcher` из библиотеки `aiogram`.
- Токен API: Указывается токен API для доступа к Telegram-боту. Этот токен уникален для каждого бота и используется для аутентификации.
- Создание объекта бота: Создается объект бота, используя указанный токен API. Этот объект будет использоваться для отправки и получения сообщений через Telegram API.
- Создание диспетчера: Создается диспетчер (`Dispatcher`), который будет управлять обновлениями от бота, такими как сообщения и команды. Диспетчер используется для регистрации обработчиков и управления потоком обновлений.

3.4 Функции functions.py
Этот файл содержит код для загрузки предобученной модели и функции для проверки существования файлов с последующим их удалением.
Загрузка модели MobileNetV2
В начале файла загружается предобученная модель MobileNetV2 с весами, обученными на наборе данных ImageNet. Эта модель используется для задач классификации изображений. Код выглядит следующим образом:
model = tf.keras.applications.MobileNetV2(weights='imagenet')
Функция проверки существования файлов и их удаления
Функция check_and_delete_file предназначена для проверки существования файла по указанному пути и удаления его, если он существует. Функция принимает один аргумент file_path, который представляет путь к файлу.
Код функции выглядит следующим образом:
def check_and_delete_file(file_path):
    if os.path.exists(file_path):  # Проверяем, существует ли файл по указанному пути
        os.remove(file_path)  # Удаляем файл, если он существует
        print(f"Файл {file_path} был удален.")  # Выводим сообщение о том, что файл был удален
    else:
        print(f"Файл {file_path} не существует.")  # Выводим сообщение, что файл не найден
Пошаговое объяснение:
Проверка существования файла:
if os.path.exists(file_path): Используется функция os.path.exists, чтобы проверить, существует ли файл по указанному пути file_path.
Удаление файла:
os.remove(file_path): Если файл существует, он удаляется с помощью функции os.remove.
Вывод сообщений:
print(f"Файл {file_path} был удален."): Если файл был успешно удален, выводится сообщение об этом.
print(f"Файл {file_path} не существует."): Если файл не найден по указанному пути, выводится соответствующее сообщение.
Функция classify_and_check_image загружает изображение, изменяет его размер, преобразует в массив и предобрабатывает для модели. Затем модель делает предсказание, и декодированные результаты проверяются на наличие заблокированных меток. Если хотя бы одна метка из списка заблокированных присутствует, функция возвращает False, иначе True.
Функция detect_selfie загружает изображение, преобразует его в оттенки серого и использует каскад Хаара для обнаружения лиц. Если на изображении найдено хотя бы одно лицо, функция возвращает True, в противном случае False.
Функция faceswap – берёт исходное изображение и заменяет лицо на нём на лица из всех изображений в указанной папке. Результаты сохраняются, а пути к ним возвращаются. Если возникает ошибка, она выводится в консоль.
Функция convert_to_sticker – преобразует изображение в формат WEBP с размером 512x512, обрезая его до квадрата и сохраняя с оптимальными настройками. Возвращает путь к готовому стикеру.
Функция generate_referral_link – создаёт уникальную реферальную ссылку для пользователя, сохраняет её в базу данных и возвращает URL.
Функция create_connection – открывает соединение с SQLite-базой данных (referrals.db).
3.5 Хэндлеры handlers.py
Этот файл содержит обработчики и вспомогательные функции, используемые ботом для обработки входящих сообщений и выполнения различных операций с изображениями.
База данных SQLite – создаёт две таблицы: users (ID и попытки) и referrals (реферальные ссылки с привязкой к пользователям).
Очереди – хранят последние 1000 замеров времени обработки и использования памяти.
Клавиатуры – две inline-клавиатуры: для выбора пола (Мужской/Женский) и кнопка Подписаться на канал.
Словарь user_gender – хранит выбранный пользователями пол.
show_menu – отправляет пользователю список доступных команд (/start, /set_gender, /refer).
send_referral_link – генерирует и отправляет пользователю его реферальную ссылку.
cmd_start – обработчик команды /start:
Регистрирует нового пользователя в БД (если его нет) с 3 попытками.
Если передан реферальный ID, начисляет дополнительную попытку пригласившему.
Отправляет приветственное сообщение и проверяет подписку на канал.
Проверка рефералов:
Если пользователь перешёл по реферальной ссылке, пригласивший получает +1 попытку.
Пригласившему отправляется уведомление о новом участнике.
Работа с подпиской:
Пользователю предлагается подписаться на канал (subscribe_keyboard).
Через секунду запускается проверка подписки (check_subscription).
check_subscription
Проверяет, подписан ли пользователь на указанный канал (CHANNEL_ID).
Если подписан — предлагает выбрать пол (gender_keyboard).
Если нет — просит подписаться.
В случае ошибки уведомляет пользователя.
change_gender
Обработчик команды /set_gender.
Отправляет клавиатуру выбора пола (gender_keyboard).
set_gender
Обрабатывает выбор пола (кнопки male/female).
Сохраняет выбор в словарь user_gender по ID пользователя.
Через 1 секунду отправляет инструкции по загрузке фото.
Логика работы:
После проверки подписки → выбор пола → запрос фото.
Пол сохраняется для дальнейшего использования (например, в faceswap).
Фото должно соответствовать требованиям (четкое, без аксессуаров и т.д.).
Описание кода обработки изображений
Когда пользователь отправляет фото, бот выполняет следующие действия:
1. Проверка возможностей обработки
Смотрит в базе данных, сколько у пользователя осталось бесплатных попыток обработки.
Если попыток нет - предлагает пригласить друзей по реферальной ссылке для получения дополнительных попыток.
2. Обработка фото (если попытки есть)
Проверяет, что на фото действительно есть человеческое лицо (используя функцию detect_selfie).
В зависимости от выбранного ранее пола (мужской/женский) применяет разные наборы шаблонов для замены лица.
Сохраняет временные файлы в папках temp_images и result_images.
3. Создание и отправка результатов
Формирует набор обработанных фото (постер, портрет) и отправляет их пользователю.
Конвертирует результаты в формат стикеров Telegram.
Создает персональный стикерпак для пользователя и отправляет ссылку на него.
Уменьшает счетчик оставшихся попыток на 1.
4. Очистка и мониторинг
Удаляет все временные файлы после обработки.
Замеряет и выводит в консоль статистику по времени обработки и использованию памяти.
Ловит и обрабатывает возможные ошибки, отправляя пользователю понятные сообщения.
5. Дополнительные функции
Показывает статус "Отправляет фото..." во время обработки.
Предлагает поделиться результатами в соцсетях с хештегом.
Дает рекомендации по качеству фото при ошибках распознавания лица.
